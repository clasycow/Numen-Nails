NUMEN NAILS PHOTO FOLDER

The gallery has nine nail sets containing all 22 supplied photos.
Each set has one cover card. Opening it shows that set's photos together,
with previous/next arrows, thumbnails, keyboard arrows, and touch swiping.
Six sets appear initially; Show all sets and Show fewer control the rest.

ADDING ANOTHER PHOTO OF AN EXISTING SET

1. Copy the photo into this folder, using a unique filename.
2. In index.html, find that set's article inside #nailGallery.
3. Add an img inside its <template class="nail-set-photos">. Copy an existing
   image line and update src, alt, width, and height for the new photo.
4. Keep class="nail-set-photo", loading="lazy", and decoding="async".
   The photo count and viewer update automatically on page load.
5. If you change the cover, also update the image inside .nail-set-cover.

ADDING A DIFFERENT NAIL SET

Copy one complete set article, including its template, before the
nail-card-callout article. Give it a unique data-set-id, then update its
name, description, service, category, cover, image descriptions, and photos.
Update the displayed set number and initial photo-count/accessible labels.
Use a separate card only for a different design, not for another angle.

PHOTO SHAPE AND ORIENTATION

Cards, the main viewer, and thumbnails use consistent horizontal 3:2 frames.
Photos fit fully inside them without stretching or cropping the nail art.
Portrait photos stay upright in the wide frame. The sideways angle of the
Chinese Press-Ons (nail12.jpg) uses data-rotation="-90" to display upright.
Keep that attribute only on photos that need a counterclockwise quarter turn.
The original photo files remain unchanged.

GALLERY PREVIEW AND TOOLBAR

Edit data-collapsed-count="6" on #nailGallery to change the number of sets
shown initially. Counts refer to sets; each card lists its own photo count.
The portfolio-toolbar remains commented out in index.html. Its filters
and handlers remain available if that toolbar is restored later.

Gallery layout rules are in css/nail-gallery.css, and the viewer behavior
is in js/scripts.js.
